# Laboratorios de Machine Learning: Modelos Predictivos y Clustering 🤖📊

Este repositorio contiene una colección de Jupyter Notebooks enfocados en la implementación y evaluación práctica de diversos algoritmos de Machine Learning utilizando Python. Los laboratorios abarcan técnicas de regresión, clasificación multiclase y agrupamiento.

## 📂 Contenido del Repositorio

Los archivos están distribuidos de acuerdo con el tipo de algoritmo evaluado:

### 📈 Modelos de Regresión
*   `Simple-Linear-Regression-v1.ipynb`: Fundamentos e implementación de regresión lineal simple.
*   `Mulitple-Linear-Regression-v1.ipynb`: Modelado predictivo utilizando múltiples variables independientes[cite: 6].
*   `Regression-Trees-Taxi-Tip-v1.ipynb`: Uso de árboles de regresión aplicado a un caso de predicción de propinas de taxis[cite: 6].

### 🏷️ Modelos de Clasificación
*   `Logistic-Regression-v1.ipynb`: Implementación de regresión logística para problemas de clasificación[cite: 6].
*   `Multi-class-Classification-V2.ipynb`: Estrategias para resolver problemas con múltiples clases objetivo[cite: 6].
*   `Decision-tree-classifier-drug-pred-v1.ipynb`: Uso de árboles de decisión para la predicción en un dataset médico (medicamentos)[cite: 6].
*   `KNN-lab-v1.ipynb`: Desarrollo de modelos con el algoritmo de K-Vecinos Más Cercanos (K-Nearest Neighbors)[cite: 6].
*   `decision-tree-svm-ccFraud-v1.ipynb`: Modelado enfocado en la detección de fraude con tarjetas de crédito utilizando Support Vector Machines (SVM) y Árboles de Decisión[cite: 6].
*   `Random- Forests -XGBoost-v1.ipynb`: Evaluación de algoritmos de ensamble potentes como Random Forest y XGBoost[cite: 6].

### 🧩 Modelos de Agrupamiento (Clustering)
*   `K-Means-Customer-Seg-v1.ipynb`: Aplicación del algoritmo K-Means para la segmentación de clientes[cite: 6].

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Python
*   **Entorno:** Jupyter Notebook
*   **Librerías principales:** Scikit-Learn, Pandas, NumPy, XGBoost, Matplotlib/Seaborn.
